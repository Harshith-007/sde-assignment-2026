# Simulation reports

The required simulator grade reports must be generated by running the controller
against the official simulator. They are intentionally not fabricated or checked
in as if measured.

From the repository root, with dependencies installed:

```bash
python -m sim baseline --scenario scenarios/public_01_dev.yaml --run-dir runs/base01
python -m sim serve --scenario scenarios/public_01_dev.yaml --run-dir runs/mine01
# In another terminal:
./run.sh http://127.0.0.1:8700
python -m sim grade --run runs/mine01 --baseline runs/base01 --out reports/public_01.md
```

Repeat for `public_02_incidents.yaml`. For `public_03_load.yaml`, record wall
clock duration, peak RSS, event throughput and decision lag. Capture crash
recovery by terminating the controller process mid-run and restarting it with
the same `CONTROLLER_DB` while the simulator remains running.

No measured results are included until these commands have actually completed.
